# 🏋️ Gym Membership Analytics Dashboard

## 📊 Project Overview
Interactive Power BI dashboard analyzing gym membership revenue, satisfaction, and engagement.

## 🚀 Tools & Skills
- Power BI
- Data Visualization
- KPI Analysis
- Business Intelligence

## 📈 Key Insights
- Premium memberships generate the highest revenue.
- Members aged 35+ show the highest satisfaction.
- Personal training correlates with better retention.
